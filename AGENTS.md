# Договорились — инструкции для агентов

Планер для пары в Telegram: бот + мини-приложение + обёртка Capacitor. Python 3.11, aiogram 3, aiohttp,
SQLite в `/data`, деплой на Amvera. Файл читают ThinkRail (через `pi`), Claude Code (`CLAUDE.md` → сюда),
Codex и другие агенты.

## Что читать

- `goal-and-requirements.md` — зачем продукт и что в него не входит (корень графа спецификаций).
- `architecture.md` — процесс, модули, данные, инварианты.
- `DESIGN.md` — перед **любой** правкой интерфейса.
- `webapp/SPEC.md`, `mobile/SPEC.md` — когда трогаете эти части.
- `docs/AUDIT-pre-launch.md` — открытые проблемы; не создавайте новые того же рода.
- `docs/TOOLS.md` — инструменты для проверки своего приложения.

Спецификации — markdown с frontmatter (`id`, `type`, `title`, `status`, `parent`) в формате spec-graph
ThinkRail. Меняете границу модуля, контракт API или решение — сначала обновите спецификацию.

## Инварианты

- Каждый SQL-запрос к делам, проектам, этапам и чату ограничен `couple_id` пользователя; `couple_id`
  берётся только из записи пользователя, никогда из тела запроса.
- Все `/api/*` проходят middleware `auth` в `web.py` (initData Telegram или сессия приложения).
- Модель (YandexGPT) только предлагает разбор; код проверяет ответ (`parser.py`). Без ключей всё работает
  на правилах — не ломайте этот путь.
- Очки игры пишет только сервер, повторы отсекает уникальный ключ (`game.py`).
- Пользовательский текст в HTML — через `esc()` в мини-приложении и `html.escape` в боте (`parse_mode=HTML`).
- Секреты только из переменных окружения (`config.py`). В `webapp/`, `mobile/` и CI — ни одного ключа.
- Тексты для людей — на русском, живые, с юмором из `jokes.py`; без канцелярита.

## Проверка

```
pip install -r requirements.txt pytest pytest-aiohttp
python -m pytest -q
```

Изменили интерфейс — снимите скриншоты `/tg?demo` светлой и тёмной темы на 320px и положите в
`screenshots/`. Перед первой оплатой или крупным релизом — скилл `pre-launch-audit` (`.claude/skills/pre-launch-audit/SKILL.md`; ThinkRail и Claude Code находят его сами).

## Нельзя без спроса

Менять схему БД без снимка и плана отката, трогать данные на Amvera, менять токены, публиковать сборки
в сторы.
