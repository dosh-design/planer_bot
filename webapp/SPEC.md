## Ответственность

Один файл `index.html` без сборки: разметка, стили и скрипт. Открывается как `/tg` (Telegram), `/app`
(Capacitor) и `/` (в браузере без Telegram — демо по `?demo`). `privacy.html` — политика.

## Граница

- Говорит с сервером только через `/api/*` и `/auth/*` из `web.py`; данные пары в браузере не хранит.
- Демо-режим работает на выдуманных данных в памяти и не делает запросов к API.
- Визуальные решения — только из `DESIGN.md` (токены в начале файла).
- Любой пользовательский текст в разметке — через `esc()`.

## Состояния

Загрузка, пусто, ошибка (401 / нет связи / прочее) и офлайн обязательны для каждого экрана.
