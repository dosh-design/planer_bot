## Процесс

Один процесс (`main.py`): polling бота aiogram, цикл напоминаний раз в минуту и веб-сервер aiohttp
на порту 80. Хранилище — один файл SQLite `/data/family.sqlite3` (постоянный том Amvera).

## Модули

| Модуль | Ответственность | Зависит от |
|---|---|---|
| `bot.py` | чат: приглашение пары, текст, голос, пересылки, кнопки, команды | planner, parser, stt, db |
| `planner.py` | бизнес-логика: добавление, конфликты, напоминания, сводка, пинки | db, jokes, game |
| `parser.py` | фраза → записи: YandexGPT с проверкой кодом, иначе правила | names, config |
| `stt.py` | голос → текст (SpeechKit, до 30 с) | config |
| `game.py` | очки, недельные матчи, достижения | db |
| `ics.py` | импорт календаря | — |
| `db.py` | схема, миграции при старте, все запросы | — |
| `web.py`, `webapp_auth.py` | HTTP: страницы, `/auth/*`, `/api/*`, проверка initData | planner, db |
| `webapp/` | мини-приложение, см. [[webapp]] | API `web.py` |
| `mobile/` | Capacitor-обёртка, см. [[mobile]] | `/app` |

`db.py` — единственный, кто пишет SQL. `bot.py` и `web.py` не обращаются к модели напрямую — только через
`planner`/`parser`.

## Решения

- **SQLite, а не Postgres:** одна пара — десятки записей; один процесс; бэкап — копия файла.
  Цена: нет RLS, изоляция держится на `couple_id` в каждом запросе (инвариант в `AGENTS.md`).
- **Миграции при старте** (`ADD COLUMN` по `PRAGMA table_info`). Только добавление; любое удаление или
  переименование требует снимка базы и записанного отката.
- **Ачивки со ступенями:** каждое повторное получение — строка `game_feats` с ключом повода (дата, неделя,
  дело, проект), поэтому один повод считается один раз; ступени — строки `game_achievements` с кодом `код:ступень`.
  «Сделано вместе» и «Уютный дом» считаются прямо по `game_events`. Таблица только добавлена: откат — старый код
  её не читает. Все ачивки командные, без подсчёта, кто из двоих что сделал.
- **Один часовой пояс** (`TZ_NAME`). Известное ограничение, план — пояс у пары (аудит, п. 17).
- **Модель предлагает, код решает:** ответ YandexGPT валидируется, при сбое — правила.
