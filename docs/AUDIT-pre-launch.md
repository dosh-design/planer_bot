## Требуется ваше подтверждение

- **История git на утечки:** `git clone https://github.com/dosh-design/planer_bot && cd planer_bot &&
  gitleaks detect --source . --log-opts="--all" -v`. Нашлось — отозвать токен в @BotFather (`/revoke`),
  перевыпустить ключ Yandex, обновить переменные на Amvera.
- **Бюджет Yandex Cloud:** Billing → платёжный аккаунт → «Бюджеты» → «Создать», сумма расходов на каталог
  `YANDEX_FOLDER_ID`, пороги 50/80/100 % на почту; плюс квоты Foundation Models и SpeechKit.
- **Снапшоты Amvera:** проект → хранилище `/data` — есть ли снимки и как часто; восстановить в тестовый
  проект и выполнить `sqlite3 family.sqlite3 "PRAGMA integrity_check; SELECT COUNT(*) FROM items;"`.
