# Аудит перед первой оплатой

Проверь проект по 23 пунктам. **Ничего не меняй.** Раздели работу на пять независимых агентов
(только чтение): 1) дизайн и производительность, 2) безопасность, 3) платежи, 4) данные,
5) работа после запуска.

Для каждого пункта: вердикт PASS / FAIL / PARTIAL / N/A, файл:строка, причина, предложение.
Если проверить можно только в панели сервиса — пометь «Требуется моё подтверждение» и дай пошаговую
инструкцию. Бэкап и восстановление — только на тестовой базе, платежи — только в тестовом режиме,
боевые данные не трогать.

Сначала покажи сводную таблицу и сохрани её в `docs/AUDIT-pre-launch.md` (с датой).
Ничего не исправляй, пока владелец не подтвердит.

## Пункты

**Дизайн и производительность**
1. Один документ дизайн-системы (`DESIGN.md`), которому следуют все цвета, размеры шрифта и отступы.
2. Отдельные состояния для загрузки, пустого списка и ошибки.
20. Имена с апострофами, эмодзи и RTL-текст не ломают поля и вывод.
21. Картинки в WebP/AVIF, всё ниже первого экрана грузится лениво.
22. Индексы на самых фильтруемых полях.

**Безопасность**
3. Секретные ключи только на сервере; фронтенд и история git проверены на утечки; засвеченные ключи перевыпущены.
4. Каждый API-эндпоинт проверяет аутентификацию и права на сервере (в SQLite — фильтр владельца в каждом запросе).
5. Лимиты или оповещения о расходах на все платные сервисы (ИИ, SMS, почта).

**Платежи**
6. Вебхуки проверяют подпись; повторное уведомление об одном платеже не засчитывается дважды.
7. Возвраты, отмены и неудачные списания проверены в тестовом режиме.
8. Доступ закрывается вовремя, когда кончается пробный период или подписка.
9. При переходе с test на live пересоздаются ключи и секрет вебхука.
10. Деньги — целые числа в минимальных единицах (копейки), никогда float.
11. Двойной клик по кнопке создаёт один заказ.
12. НДС / налоги и онлайн-чеки (54-ФЗ) настроены под статус продавца.

**Данные**
13. Условия использования и политика конфиденциальности совпадают с тем, как приложение работает.
14. Ежедневные автоматические бэкапы; восстановление один раз проверено в новую базу.
15. Откат для каждой миграции схемы, проверенный на копии.
16. Списки больше 1000 строк не обрезаются молча.
17. Время хранится с поясом; у пользователя свой пояс, напоминания приходят по местному времени.
18. Сначала мягкое удаление; удаление аккаунта стирает данные навсегда.
19. Пользователь может выгрузить свои данные.

**Работа после запуска**
23. Подключён мониторинг ошибок: владелец узнаёт о проблеме первым.
